# HP-42S clone — Plus42 on an ESP32-S3

An HP-42S-shaped calculator: e-paper display, LiPo cell, USB-C and BLE, a
custom keypad PCB with metal dome switches, a resin-printed case, running
[Plus42](https://thomasokken.com/plus42/) on an ESP32-S3.

Case dimensions follow the original HP-42S as closely as the parts allow:
**148 × 80 × 15 mm**.

## What is in here

| Path | What it is |
|---|---|
| `elec/src/*.ato` | The wiring, as [atopile](https://atopile.io) source. Compiles to a netlist. |
| `elec/footprints/hp42s.pretty/` | KiCad footprints generated by `tools/gen_dome_footprints.py`. |
| `elec/layout/` | The KiCad project. Placement and routing live here. |
| `tools/gen_dome_footprints.py` | Parametric generator for the Snaptron dome sites. |
| `docs/connections.md` | The connection table in prose, with the reasoning. |
| `docs/keypad-geometry.md` | The measured key grid, and the clearances that follow. |
| `docs/kicad-setup.md` | Getting the netlist into KiCad without a wall of errors. |
| `firmware/` | The Plus42 port. Not started. |
| `hardware/` | Case and keycap files. Barnaby's own CAD. |

## Building the netlist

```
pip install atopile        # 0.2.69 at time of writing
ato build
```

Output lands in `build/`: `default.net` (KiCad netlist), `default.csv` (BOM),
and a designator map. atopile does the wiring and the netlist; it does **not**
place or route. Layout stays in KiCad.

## Headline choices

- **MCU** — ESP32-S3-MINI-1-N8. The S3 over the C3/C6 because only the S3 has
  full USB OTG, which is what allows drag-and-drop file transfer as a mass
  storage device. The `-N8` specifically: it has no PSRAM, and octal PSRAM
  would eat GPIO33–37, where the panel interface lives.
- **Display** — Good Display GDEY0266T90, 2.66", 296 × 152 px in a 71.82 ×
  36.30 mm outline. Plus42 character cells are 6 × 8 px, so at 2× scale this
  gives **24 columns × 9 rows** against Plus42's 22 × 8 default. The obvious
  2.9" panel is 79.0 mm wide and will not fit an 80 mm shell.
- **Power** — BQ25185 charger with power path → TPS63900 buck-boost to 3.3 V →
  MAX17048 fuel gauge. The buck-boost is mandatory: the panel's VCI cannot
  take 4.2 V.
- **Keypad** — 37 keys, 6 columns × 7 rows, no diodes. Columns sit on
  RTC-capable GPIOs and wake the chip from deep sleep via `ext1`, so there is
  no scanner IC and no standing current. The physical grid is measured off a
  real 42S and is not uniform: 12.5 mm columns on the function rows, 15 mm
  across the numeric block.
- **Battery life** — roughly **15 months** on the 1650 mAh cell that fits, at
  2 h/day and 1500 keystrokes. About 33 hours of continuous execution.

## What is not settled

- **Display technology.** E-paper costs about 0.4 s per keystroke. A Sharp
  LS027B7DH01 memory LCD gives 33 × 15 cells and millisecond updates within
  the same 80 mm width, at the price of a nominally 5 V part and a patchier
  supply. On the numbers the memory LCD is the stronger option. Undecided.
- **Pin numbers.** Every IC in `elec/src/parts.ato` declares its pins by
  *name*, not number. The netlist is therefore correct about what connects to
  what and says nothing about which physical pin that is. Reconciling names
  against real KiCad symbols is a job that has not been done.
- **Dome pad geometry.** `tools/gen_dome_footprints.py` says so at the top: the
  ring dimensions are derived from one published figure and scaled. Pull the
  real Snaptron pad drawing before fab.
- **Panel charge pump.** Not in the source. Copy it from Good Display's
  reference schematic for this exact panel.
